# Replit Agent Prompt — The Magic Hack: Internal Business Dashboard

## What to Build

A **full frontend web application** (React + Tailwind CSS) for an internal business management dashboard called **Magic Hack OS**. This is a **UI/UX build only** — use static mock data for now. No backend, no API calls, no authentication logic. All data is hardcoded in JS/JSON files. Backend connections will be added later.

---

## Tech Stack

- **React** (with Vite)
- **Tailwind CSS** (custom config with brand tokens)
- **React Router v6** (multi-page navigation)
- **Recharts** (for charts and graphs)
- **Lucide React** (icons only — no other icon library)
- **date-fns** (date formatting)

## Design System — CRITICAL, follow exactly

### Color Palette

```js
// tailwind.config.js
colors: {
  black:        '#000000',
  surface:      '#0d0d0d',  // page background
  card:         '#111111',  // card background
  border:       '#004c1e',  // ALL borders, dividers, outlines → dark green
  'border-dim': '#002910',  // subtle borders, inactive
  accent:       '#00fe65',  // electric green — USE VERY SPARINGLY
  white:        '#ffffff',
  'gray-400':   '#9ca3af',
  'gray-600':   '#4b5563',
}
```

### How to Use Colors

| Element | Color |
|---|---|
| Page background | `#000000` |
| Cards / panels | `#111111` |
| All borders and outlines | `#004c1e` |
| Sidebar border-right | `#004c1e` |
| Table row dividers | `#002910` |
| Primary headings | `#ffffff` |
| Secondary text / labels | `#9ca3af` |
| Primary CTA button | bg: `#004c1e`, text: `#ffffff`, hover border: `#00fe65` |
| Active nav item indicator | `#00fe65` left border only |
| Active status badge | `#00fe65` dot only, text white |
| Key KPI number (positive) | `#00fe65` |
| Notification dot | `#00fe65` |
| Input focus ring | `#00fe65` at 40% opacity |
| Everything else | dark greens or white/gray |

### Electric Green `#00fe65` Rules
- **Maximum 3 instances per screen**
- Never use as a fill/background
- Only for: active state indicators, positive metric values, the single most important CTA per screen, notification/alert dots
- When in doubt → use `#004c1e` instead

### Typography

```css
Font family: 'Inter', system-ui, sans-serif (import from Google Fonts)
font-size base: 14px
Headings: font-weight 600, tracking tight
Labels/meta: font-size 12px, color #9ca3af, uppercase, letter-spacing wide
Numbers/KPIs: font-family monospace fallback, font-weight 700
```

### Component Style Rules

- **Cards:** `bg-[#111111] border border-[#004c1e] rounded-lg`
- **Inputs:** `bg-[#0d0d0d] border border-[#004c1e] rounded-md text-white focus:ring-1 focus:ring-[#00fe65]/40`
- **Buttons primary:** `bg-[#004c1e] text-white hover:border hover:border-[#00fe65]`
- **Buttons ghost:** `border border-[#004c1e] text-white hover:bg-[#004c1e]/20`
- **Badges/Status pills:** small, rounded-full, bg dark, colored left-dot only
- **Tables:** header bg `#0d0d0d`, rows `#111111`, dividers `#002910`, hover `#004c1e/10`
- **Sidebar:** bg `#000000`, right border `#004c1e`, width 240px collapsed to icons at 64px
- **No shadows** — use borders instead
- **Corners:** rounded-lg (8px) for cards, rounded-md (6px) for inputs/buttons
- **Spacing:** generous padding (p-6 for cards, p-4 for compact items)

## Final Requirements

1. **Fully responsive** — works at 1280px+ desktop width minimum
2. **No light mode** — dark only, always
3. **Smooth transitions** — 150ms ease on hover states, 200ms for panel slides
4. **Empty states** — every list/table has a styled empty state with icon and text
5. **Loading skeletons** — add skeleton placeholders on all data lists (even if static, show them briefly on mount)
6. **No placeholder images** — use colored initials avatars everywhere
7. **Colombian formatting** — dates as DD/MM/YYYY, currency with dots as thousands separator (e.g., $48.500.000)
8. **All text in Spanish**
9. **Do not connect to any API or backend** — all data from `/src/data/` files
10. **Do not add authentication** — open app, straight to dashboard
